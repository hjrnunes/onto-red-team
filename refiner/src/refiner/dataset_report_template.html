Dataset Report

Generated adversarial test prompts with their source metadata and domain context.

Each row represents one adversarial prompt. The emit stage generates these by:

  • Sampling one enumeration value per variation axis (weighted by relevance)
  • Selecting an adversarial technique (social engineering frame)
  • Constructing a generation prompt with the policy concept, risk, sampled values, and technique
  • Generating the adversarial prompt via LLM, grounded in the domain context

The distribution charts show how evenly prompts cover policies, risks, techniques, and ontologies.
